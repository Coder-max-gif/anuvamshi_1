# PROMPT 06 — ADD ONLY USEFUL WEBGL AND MOTION ENHANCEMENTS

Inspect the working Canvas website first. Do not replace it.

Add Three.js / React Three Fiber only where it materially improves the supplied video experience:
- subtle 2.5D depth/parallax
- restrained depth-map displacement only if a real depth map is available
- subtle lighting or shader transitions
- controlled spatial camera movement
- optional subtle atmospheric detail only if it suits the footage

Do not claim a flat frame sequence is a fully reconstructed 3D scene. Do not add arbitrary 3D spheres, finance symbols, floating charts or unrelated scenes. Do not obscure the person.

Coordinate Framer Motion and GSAP ScrollTrigger without competing scroll systems. Keep native scrolling. Respect reduced motion. Provide Canvas-only fallback when WebGL is unavailable.

Refine text reveals, section timing, transitions and navigation. Motion should feel cinematic and purposeful, not busy.
